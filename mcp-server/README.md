# 🎓 KemSU EIOS MCP Server (`kemsu-eios`)

> Официальный локальный MCP-сервер (Model Context Protocol) для интеграции **ЭИОС КемГУ (ИнфоОУПро)** с AI-агентами: **Google Antigravity**, **Claude Desktop**, **Cursor**, **Continue**, **Roo Code** и другими LLM-инструментами.

---

## ⚡ Возможности

- 📋 **Профиль студента**: мгновенное получение данных (ФИО, факультет/институт, специальность, семестр).
- 📚 **Все дисциплины и прогресс**: список предметов, преподаватели, баланс баллов БРС и счетчики сдачи.
- 🎯 **Умная фильтрация заданий**: поиск лабораторных по статусам (`TODO` — надо сделать, `REVIEW` — на проверке, `DONE` — сдано, `REWORK` — на доработке), датам дедлайнов и названиям.
- 📥 **Автоскачивание методичек**: агент может сам скачать прикрепленные преподавателем файлы (PDF, DOCX, ZIP) в папку `downloads/` и прочитать их.
- 🚀 **Сдача решений**: прямая загрузка готового файла работы (DOCX / ZIP) с темой и комментарием в систему КемГУ.
- 💻 **Консольная утилита (CLI)**: работа с заданиями прямо из терминала без нейросети.

---

## ❓ Работает ли сервер только с расширением браузера?

**НЕТ, не только с расширением!** Сервер поддерживает **два независимых режима работы**:

### 1. Автономный режим (Standalone — без расширения)
- Сервер работает полностью самостоятельно через собственный встроенный сетевой краулер.
- Достаточно передать актуальную куку сессии `JSESSIONID` (или указать учётные данные в `.env`), и сервер сам подключается к `xiais.kemsu.ru`, обходит все предметы и парсит свежие лабы.
- Браузер и расширение при этом могут быть полностью закрыты.

### 2. Режим тандема с расширением XIAS (Рекомендуемый)
- Если в Google Chrome установлено расширение XIAS, оно в фоновом режиме на лету автоматически зеркалирует все ваши предметы, открытые задания и сессию в локальный MCP-сервер через `http://127.0.0.1:38421`.
- Не требуется хранить пароли в открытом виде на диске.

## 🚀 Быстрый старт

### Требования
- Установленный [Node.js](https://nodejs.org/) (версия 18 или выше).

### Установка

1. Перейдите в папку сервера:
   ```bash
   cd mcp-server
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```

## ⚙️ Настройка подключения в AI-клиентах

### 1. Google Antigravity
В файле `~/.gemini/config/mcp_config.json` (в Windows: `C:\Users\<Ваш_Пользователь>\.gemini\config\mcp_config.json`):

```json
{
  "mcpServers": {
    "kemsu-eios": {
      "command": "node",
      "args": ["<АБСОЛЮТНЫЙ_ПУТЬ_К_ПАПКЕ>/mcp-server/index.js"]
    }
  }
}
```

### 2. Claude Desktop
В файле конфигурации Claude Desktop (`claude_desktop_config.json`):

```json
{
  "mcpServers": {
    "kemsu-eios": {
      "command": "node",
      "args": ["<АБСОЛЮТНЫЙ_ПУТЬ_К_ПАПКЕ>/mcp-server/index.js"]
    }
  }
}
```

### 3. Cursor / Continue / VS Code
Добавьте сервер с типом `stdio`, указав команду `node` и аргумент пути к `index.js`.

## 🛠️ Доступные инструменты (Tools) для AI

AI-модель автоматически получает доступ к следующим функциям:

| Инструмент | Параметры | Описание |
| :--- | :--- | :--- |
| `eios_get_student_info` | — | Информация о студенте, институте, группе и сводная статистика. |
| `eios_list_courses` | `search` *(опц.)* | Список всех изучаемых дисциплин, преподавателей и прогресса выполнения. |
| `eios_get_tasks` | `status`, `course`, `search`, `limit` | Список заданий с фильтрацией (`TODO`, `REVIEW`, `DONE`, `REWORK`), дедлайнами и ссылками. |
| `eios_get_task_details` | `taskId` или `taskTitle` | Полные требования к конкретной работе, комментарий преподавателя и ссылки на файлы. |
| `eios_download_material` | `url`, `filename` *(опц.)* | Скачивает файл задания/методички на диск в `downloads/` для последующего анализа агентом. |
| `eios_submit_solution` | `taskId`, `filePath`, `solutionTitle`, `comment` | Загружает готовый файл решения (DOCX/ZIP) на портал ИнфоОУПро. |
| `eios_refresh_data` | `cookies` *(опц.)* | Принудительно подключается к серверу КемГУ и скачивает свежий список заданий. |
| `eios_sync_status` | — | Проверка статуса моста и даты последней синхронизации. |
| `eios_export_snapshot` | — | Экспорт полного сырого JSON-снимка базы данных студента. |

## 💻 Использование через терминал (CLI)

Сервер включает удобную утилиту `cli.js`, позволяющую работать с базой ЭИОС прямо из командной строки:

- **Показать информацию о студенте:**
  ```bash
  node cli.js student
  ```

- **Список всех дисциплин и прогресса сдачи:**
  ```bash
  node cli.js courses
  ```

- **Список только тех работ, которые ещё надо сделать (`TODO`):**
  ```bash
  node cli.js tasks --status=TODO
  ```

- **Фильтр работ по конкретному предмету:**
  ```bash
  node cli.js tasks --course="Базы данных"
  ```

- **Подробности о конкретной лабораторной:**
  ```bash
  node cli.js details "Лабораторная работа 2"
  ```

- **Автономное обновление базы с сервера КемГУ:**
  ```bash
  node cli.js refresh
  ```
  *(или с явной передачей сессии: `node cli.js refresh "JSESSIONID=..."`)*

- **Проверка статуса базы и наличия сессии:**
  ```bash
  node cli.js status
  ```

## 🔒 Безопасность и конфиденциальность

- Все данные сохраняются **только локально** на вашем компьютере в `data/eios_cache.json`.
- Никакие пароли или персональные идентификаторы не передаются сторонним облачным сервисам.
- Файлы конфигурации `.env` и кэш исключены из репозитория через `.gitignore`.
