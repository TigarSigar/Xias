# XIAS — ЭИОС+ КемГУ & TickTick Integration

**XIAS** — это расширение для Google Chrome (Manifest V3), которое модернизирует устаревший интерфейс ЭИОС / ХИАИС КемГУ (ИнфоОУПро), избавляет от постоянных вылетов сессии, организует домашние задания по статусам и автоматически синхронизирует лабы с вашим **TickTick**.

---

## ⚡ Главные возможности

1. **Бесшовный автологин и защита от разлогина (Keep-Alive):**
   * Больше никаких внезапных вылетов во время работы. Сервис-воркер каждые 5 минут незаметно обновляет сессию.
   * При открытии формы входа `eios.kemsu.ru` расширение автоматически подставляет сохранённые логин и пароль и нажимает «Войти».
   * При падении сессии на `xiais.kemsu.ru` (ошибки *NullPointerException / Нет доступа*) происходит мгновенный автоматический релогин через SSO без вашего участия.

2. **Современный Dashboard вместо серых таблиц 2000-х годов:**
   * Красивые адаптивные карточки для каждого предмета (*«Разработка бизнес приложений»*, *«Тестирование ПО»*, *«Основы научной деятельности»* и др.).
   * Сводная статистика: сколько предметов, сколько лаб нужно сдать, сколько сейчас на проверке у преподавателя, общий рейтинг БРС.
   * Фильтрация в один клик: **«Все»**, **«🔴 Надо сделать»**, **«🟡 На проверке»**, **«🟢 Оценено»**.
   * Мгновенный живой поиск по названию лабы или дисциплины.
   * Кнопка **«👁 Старый вид»** позволяет в любой момент вернуться к оригинальной таблице.

3. **Умная интеграция с TickTick:**
   * Кнопка **«+ TickTick»** у каждой лабы с автоматическим распознаванием дедлайна (с точностью до минуты!).
   * Кнопка **«✓ Синхронизировать с TickTick»** на главном дашборде — отправляет все несданные работы разом.
   * Автоматически создает папку/список **«КемГУ / Учёба»** и вешает теги `#КемГУ`, `#Лаба`.
   * Дедупликация: повторные нажатия не создают одинаковые задачи в TickTick.

## 🚀 Установка расширения в Chrome (за 30 секунд)

1. Откройте в браузере страницу управления расширениями: `chrome://extensions/`
2. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
4. Выберите папку проекта: `c:\Users\Egor\Desktop\XIAS`.
5. Готово! Иконка XIAS появится на панели расширений Chrome.

---

## ⚙️ Настройка TickTick и Автологина

1. Нажмите на иконку **XIAS** на панели расширений браузера (можно закрепить её булавкой).
2. **Как получить токен TickTick:**
   * Перейдите в [Кабинет разработчика TickTick](https://developer.ticktick.com/manage) (или *Настройки TickTick → Интеграции → Open API*).
   * Сгенерируйте **Personal Access Token** (или создайте приложение).
   * Скопируйте токен и вставьте в поле **«Токен TickTick»** в расширении.
   * Нажмите **«Проверить токен»** — появится статус `✓ Успешно (ваше имя)`.
3. **Автологин:**
   * Введите ваш номер зачетки / логин (например, `stud12345`) и пароль от личного кабинета ЭИОС. Все данные сохраняются исключительно локально в защищенном хранилище браузера (`chrome.storage.local`).
   * Убедитесь, что галочки «Включить бесшовный автологин» и «Фоновый Keep-Alive» активны.

## 💻 Структура проекта

```
XIAS/
├── manifest.json              # Манифест расширения Manifest V3
├── icons/                     # Иконки приложения (16x16, 48x48, 128x128)
├── background/
│   └── background.js          # Фоновый воркер (alarms, keepalive пинг, API TickTick)
├── content/
│   ├── parser.js              # Парсер таблиц курсов, луп и заданий в ИнфоОУПро
│   ├── autologin.js           # Обработчик форм логина и SSO-релогина
│   ├── ticktick_client.js     # Клиент для отправки задач в TickTick
│   ├── ui.js                  # Рендер современного дашборда и плавающих панелей
│   ├── content.js             # Точка входа скриптов
│   └── styles.css             # Стили оформления современного UI
└── popup/
    ├── popup.html             # Окно настроек расширения
    ├── popup.js               # Логика настроек и проверки подключения
    └── popup.css              # Оформление окна настроек
```
